Privacy Policy

Last updated: 11 November 2026

GTA Madness Uploader ("the app") is a personal tool run by the owner of GTA Madness Clips. It is used only to upload our own videos to our own social media accounts.

What data the app uses

  • Access to our own YouTube, Instagram and TikTok accounts, granted by us through each platform's official login (OAuth).
  • Basic account information (account name and ID) to confirm the correct account is used.

How it is used

The data is used only to upload videos, set titles, descriptions and covers, and read the result of the upload. It is never sold, shared or used for advertising.

Storage

Access tokens are stored only on the owner's computer. No data is stored on any server operated by us.

Other people's data

The app does not collect, store or process data from any other users or viewers.

Revoking access

Access can be removed at any time in the security settings of the Google, Meta or TikTok account.
